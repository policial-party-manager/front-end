# 侧边导航布局方案（预览稿）

## 设计目标

将现有顶栏的业务导航移到左侧，顶栏保留品牌和用户入口。首页按“待办 → 关键数据 → 资讯与常用入口”的阅读顺序组织，让管理员先看到需要处理的工作。左侧菜单在桌面端持续可见，窄屏切换为抽屉。

## 信息架构

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 党徽与平台名、系统副标题、用户入口。HTML 预览中的角色选择仅用于评审，正式环境不展示给普通用户。 |
| 左侧主导航 | 超级管理员：首页、成员与支部、党员发展、活动与签到、资讯公告、资源中心、数据统计、系统管理；支部管理员移除系统管理；普通成员显示首页、我的培养、活动与签到、资讯公告、资源中心。 |
| 左侧底部 | 个人中心。退出登录建议放在正式页面的用户菜单。 |
| 首页 | 角色范围提示、待办事项、统计卡片、新闻/公告切换、常用入口。 |

## 布局与交互

- 左侧宽 242px，选中项用浅红底与红色竖线表示；主内容保留足够宽度，避免 8 个菜单挤在顶栏。
- 首页取消大幅轮播的首屏主导地位，用较浅的红色工作总览承接品牌感。党建新闻与公告仍可从首页进入完整列表。
- 统计和常用入口随系统角色改变。超级管理员看全院，支部管理员看本支部，普通成员看本人。
- 普通成员的“我的培养”与管理员“党员发展”属于同一业务域，但页面内容和操作范围不同。党员发展身份不作为系统权限角色。
- 侧边菜单是页面导航；新闻/公告是内容 Tab。菜单选中态由路由决定，资讯 Tab 切换本地内容。
- 屏幕宽度低于 680px 时使用抽屉导航，避免占用手机主内容宽度。

## 接入边界

此稿是独立 HTML 交互预览，使用示例数据，不修改现有 Vue 页面。正式实施需要同步调整 `TopNav.vue`、`App.vue`、导航数据与路由高亮，并按接口、鉴权和数据范围逐步开放按钮。文档中的目标菜单不代表对应后端能力已全部可用，尤其是支部管理、报名签到、资源和业务统计。
