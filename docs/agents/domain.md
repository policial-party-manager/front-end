# 领域文档约定

## 探索前读取

- 读取根目录 `GLOSSARY.md` 中与当前任务相关的内容。
- 若存在 `GLOSSARY-MAP.md`，按映射读取相关上下文的词汇表。
- 读取 `docs/adr/` 中与当前任务相关的架构决策记录（ADR）。

文件不存在时继续工作，无需专门报告缺失，也无需预先要求创建。
术语或决策形成后，可由 domain-modeling 技能按需补充。

## 文档布局

本仓库采用 single-context（单上下文）布局：

- `GLOSSARY.md`：领域术语及定义。
- `docs/adr/`：架构决策记录。

## 术语

输出中的领域概念沿用词汇表定义，包括 Issue 标题、设计建议和测试名称。
若所需概念尚无定义，先核对现有代码用语，再判断是否需要补充词汇表。

## ADR 冲突

实现或建议与现有 ADR 冲突时，明确指出相关 ADR、冲突内容及重新讨论的原因。
