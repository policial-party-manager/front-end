# 前端板块与角色权限规划

> 整理日期：2026-09-24；代码复核：2026-11-11。
> 依据：[开发计划](前端开发计划与策略.md)、[前后端接入现状](前后端接入现状.md)、后端 `openapi.yaml` 及控制器/服务守卫，以及当前前端导航、路由和权限配置。本文第 1～3 节描述目标信息架构，第 4～5 节区分当前实现与开放条件。

## 1. 划分结论

Web 端规划 **8 个核心功能板块**：

1. 首页
2. 成员与支部
3. 党员发展
4. 活动与签到
5. 资讯公告
6. 资源中心
7. 数据统计
8. 个人中心

另设 **系统管理** 作为超级管理员专属的扩展板块，承载角色权限、操作日志等已有后端能力。因此，按功能域计算为“8 个核心板块 + 1 个管理员扩展板块”；按顶栏入口计算，个人中心放在头像菜单，不占顶栏。

上述划分对应策略文档第 4 章的页面计划。其中，将原文 4.6 节的“新闻、公告与下载专区”拆为“资讯公告”和“资源中心”，分别承载内容发布与文件资源管理。登录认证属于应用基础能力；党建智能助手使用全局悬浮入口；微信小程序是独立终端，均不计入 Web 端业务板块。

## 2. 按系统角色展示的目标菜单

以下为原规划的入口分组；当前业务导航在左侧栏，顶部为用户菜单，具体数量和入口见第 4 节。

| 系统角色   | 顶栏数量 | 顶栏菜单                                                                       | 头像菜单           |
| ---------- | -------: | ------------------------------------------------------------------------------ | ------------------ |
| 超级管理员 |        8 | 首页、成员与支部、党员发展、活动与签到、资讯公告、资源中心、数据统计、系统管理 | 个人中心、退出登录 |
| 支部管理员 |        7 | 首页、成员与支部、党员发展、活动与签到、资讯公告、资源中心、数据统计           | 个人中心、退出登录 |
| 普通成员   |        5 | 首页、我的培养、活动与签到、资讯公告、资源中心                                 | 个人中心、退出登录 |

普通成员菜单中的“我的培养”对应同一党员发展业务域，但只展示本人数据和个人可执行的操作。菜单、按钮和数据范围都要按系统角色控制；后端必须再次校验权限及所属支部，不能只依赖前端隐藏入口。

**系统角色与党员发展身份必须分离。**超级管理员、支部管理员、普通成员是系统角色；入党申请人、积极分子、发展对象、预备党员、正式党员等是党员发展身份。当前前端的 `activist` 是 Mock 预览角色，后端没有对应系统角色，不应将“积极分子”长期作为独立权限角色。发展身份可用于培养流程和活动参与范围判断，但不能代替系统角色授权。

## 3. 板块与角色权限矩阵

| 板块             | 超级管理员：全院                                   | 支部管理员：本支部                                               | 普通成员：本人及可参与内容                                               |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 首页             | 全院成员、发展阶段、活动和待办概览                 | 本支部数据和待办                                                 | 个人培养进度、活动、材料和通知                                           |
| 成员与支部       | 成员与支部的查询、维护、Excel 导入、批量操作       | 本支部成员查询和维护、培养联系人维护；支部资料操作按最终授权开放 | 不显示管理入口                                                           |
| 党员发展         | 全院培养档案、身份调整、批量操作、材料和档案导出   | 本支部培养记录、材料及身份流程；直接调整还是提交审批待确认       | 查看个人档案和身份历史，提交思想汇报及本人材料                           |
| 活动与签到       | 全院活动创建、编辑、发布、类型管理、签到监控及统计 | 本支部活动创建、管理、签到监控及统计                             | 浏览可参与活动、报名、扫码签到、查看个人记录                             |
| 资讯公告         | 阅读及新闻、公告发布管理                           | 阅读；是否允许发布待单独授权                                     | 阅读新闻和公告                                                           |
| 资源中心         | 全局资源上传、管理和下载                           | 按支部权限上传、管理和下载                                       | 浏览和下载有权限的资源                                                   |
| 数据统计         | 全院及各支部统计、筛选和导出                       | 本支部统计、筛选和导出                                           | 不设独立统计入口；个人数据放首页和“我的培养”                             |
| 个人中心         | 查看和编辑本人允许修改的资料                       | 查看和编辑本人允许修改的资料                                     | 查看个人资料、培养档案、活动记录；编辑手机号、邮箱、头像等允许修改的字段 |
| 系统管理（扩展） | 角色权限、操作日志及相应基础配置                   | 不显示                                                           | 不显示                                                                   |

个人中心的姓名、学号、学院、班级等认证来源字段应只读；党员发展身份只能通过专门的身份调整流程变更。身份历史和签到记录不提供删除入口。批量操作、身份调整、支部调整及日志清理等操作应二次确认。

## 4. 与当前前端的对比

| 项目         | 当前实现                                                                                | 目标调整                                             |
| ------------ | --------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 业务导航     | 左侧栏：超管 9 项（含独立支部管理与系统管理）、支委 7 项、普通成员 5 项；顶部为用户菜单 | 按真实业务逐步开放侧栏对应页面，不再按旧顶栏数量判断 |
| 资讯公告     | 已有侧栏入口、真实阅读/搜索/详情和超管发布管理                                          | 保持普通成员与支委只读边界                           |
| 个人中心     | 头像菜单已含入口，已接本人资料只读查询                                                  | 编辑及个人业务记录另行接入                           |
| 系统管理     | 角色页和日志页已接；仅超管可进入                                                        | 补日志统计及正常日志数据验收，清理按需开放           |
| 支委成员权限 | 导航转到 `/members/branch` 占位页；超管成员页仅超管可访问                               | 接入新的成员范围接口，逐接口验证本支部边界           |
| 普通成员培养 | 已有 `/my-development` 入口，当前为占位页                                               | 接入本人培养档案，保留管理路由门禁                   |
| 接口接入     | 已接模块与仍为占位的模块详见现状文档                                                    | 后端已有培养、签到及部分统计，按新契约接入并验收     |

当前导航以 `src/stores/app.ts` 为准，路由入口与权限以 `src/router/index.ts`、`src/config/permissions.ts` 为准。旧 `前后端待接入接口清单.md` 已不在当前仓库，当前盘点统一见[前后端接入现状](前后端接入现状.md)。

## 5. 接口与开放条件

| 能力           | 当前契约情况                                                                               | 菜单或操作开放条件                                                     |
| -------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 超管成员与支部 | 已接真实维护、成员模板/导入；支部模板/导入尚未接入                                         | 补 #19、#22、#29 剩余项                                                |
| 支委成员与活动 | 已有 `/api/v4/members/**`、`/api/v4/activities/**` 范围接口；旧 `/api/v2/branch/**` 已删除 | 前端按新入口接入，逐接口验证守卫和跨支部拒绝；不代表支委可维护支部资料 |
| 资讯与活动浏览 | `/api/v2/content/**` 已接前端                                                              | 仍要求登录，维持已发布内容查询边界                                     |
| 资讯发布       | 超管页面已接现有管理接口                                                                   | 支委发布未获授权，继续隐藏入口                                         |
| 培养与档案     | 后端已具备身份变更、培养材料、思想汇报、学习和档案聚合等入口                               | 接前端占位路由，核对两阶段审批及身份变更服务的范围口径差异             |
| 活动报名与签到 | 后端已有报名、签到、限时二维码、四态考勤、复制与导出                                       | 接入并验收前保持对应操作不可用；实时更新和完整归档另确认               |
| 资源中心       | 通用本地附件上传已有；资源业务闭环仍需确认                                                 | 不能用通用上传代替分类、下载计数和权限契约                             |
| 数据统计       | 已有待办与阶段分布                                                                         | 前端尚未接；其他规划报表及导出另行确认                                 |
| 系统管理       | 已接角色与日志查询；统计未接                                                               | 正常日志链路依赖可用 ES；动态权限不自动映射前端菜单                    |

菜单可以用于说明目标结构，但在接口、鉴权或数据范围尚未完成时，不应把对应操作呈现为已经可用。特别是支部管理员不能直接复用仅允许超级管理员调用的 `/api/v4/admin/**` 接口。

## 6. 实施前需要确认的规则

1. 身份变更已为发起后由超管审批；接入时核对服务仍使用秘书关联的范围判据，与新成员接口的所属支部口径差异。
2. 支部管理员是否可以发布新闻、公告，以及能管理全院内容还是仅管理本支部内容。
3. 支部管理员能否创建、编辑支部资料；现有支部接口的服务端数据范围如何限制。
4. 活动报名接口已存在；不报名活动的参与名单、归档及实时更新方式仍需核对。
5. 政治身份字典及活动范围字段已有；前端采用服务端字典，具体流转限制和异常场景按当前实现验收。
6. 正式环境的学校统一身份认证与现有账号密码、邮箱验证码接口如何并存。
